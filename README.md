# Maison Coffee — Project 01

## Open the design in Figma
1. Open the Figma desktop app.
2. Create a new Design file.
3. Drag `coffee-house-figma.svg` from your computer onto the Figma canvas, or use File → Place image.
4. The SVG is a visual reference for the desktop layout. You can ungroup imported elements to inspect the composition.
5. Some SVG image links may need an internet connection. If a photo does not appear in Figma, use the matching photo URL from `index.html` as an image fill.

## Run the website
1. Open this folder in VS Code.
2. Open `index.html` in your browser (or use the Live Server extension).
3. CSS is in `styles/main.css`.
4. Photos load from Unsplash, so an internet connection is required.

## Important
This is a practice portfolio project. Replace the sample email, prices, location details and images before presenting it as a real client project. The mobile navigation icon is visual only at this stage; JavaScript interaction can be added as a later exercise.
