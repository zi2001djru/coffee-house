# Maison Coffee

A modern and elegant coffee shop website built with HTML5 and CSS3.

## Live Demo

[View Live Website](https://zi2001djru.github.io/coffee-house/)

## About the Project

Maison Coffee is a modern coffee shop website concept designed with a warm visual identity, elegant typography, and a clean layout.

The project focuses on responsive web design, visual presentation, and creating a welcoming digital experience for a specialty coffee brand.

## Features

- Modern coffee shop landing page
- Clean and elegant visual design
- Responsive layout for different screen sizes
- Coffee and product presentation
- Custom typography and visual elements
- Figma-based design reference

## Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Figma

## Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the Live Server extension.

No build tools or additional dependencies are required.

## Design Reference

The project includes an SVG design reference that can be imported into Figma for layout inspection.
